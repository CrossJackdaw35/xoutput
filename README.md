## Download & Install

> Setup notes for **XOutput** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **XOutput** from the Start menu

## What you can use it for

- Map gamepad buttons to keyboard/mouse input
- Use PlayStation/Xbox controllers on Windows
- Create per-game controller profiles
- Adjust deadzones, sensitivity, and macros
- Virtual XInput device emulation
